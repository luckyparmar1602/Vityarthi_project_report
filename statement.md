# Project Statement

## Problem Statement
Small organizations and offices often keep employee details on paper or in scattered files. This makes it slow to find a record, easy to make mistakes, and hard to update or remove information. There is a need for a simple program that stores employee data in an organized way and lets users manage it quickly without any complicated software.

## Scope of the Project
**Included:**
- Storing employee records (ID, name, department, salary) in a CSV file
- Adding, displaying, searching, updating and deleting employee records
- Menu-driven, command-line interface
- Duplicate ID checking and basic input validation
- Permanent storage of data using file handling

**Not included:**
- Graphical user interface or web interface
- Multiple user accounts, login or password protection
- Database connectivity (e.g., MySQL)
- Advanced features such as payroll calculation, attendance or report generation

## Target Users
- Small businesses, shops and offices that need a simple record-keeping tool
- HR or administrative staff who manage basic employee information
- Students learning Python file handling, CSV and dictionaries

## High-Level Features
- **Add Employee:** Create a new employee record with a unique ID
- **Display All:** View all records in a neat table format
- **Search:** Find an employee quickly using their ID
- **Update:** Modify an existing employee's details
- **Delete:** Remove an employee record
- **Persistent Storage:** All changes are saved automatically to `employees.csv`
- **Menu-Driven Interface:** Easy-to-use numbered menu with error handling for invalid choices
